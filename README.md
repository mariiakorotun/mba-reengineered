# MBA Bank 2.0 — реінжиніринг вебзастосунку онлайн-банкінгу

Курсова робота з дисципліни «Розробка та реінжиніринг програмних систем».
Вихідна система — бакалаврський проєкт *Mini Banking App* (Spring Boot 3, Thymeleaf, Azure SQL, Azure VM).

Марії Коротун ІПЗм-26-1

**Зроблено:** шаровий моноліт перетворено на **модульний моноліт** із контрактами модулів, насиченою доменною
моделлю та доменними подіями. Попутно усунено 9 дефектів, які виявив автоматизований зонд.
URL-адреси і схема БД залишилися сумісними з версією 1.0.

## Швидкий старт

```bash
./mvnw spring-boot:run        # профіль local: H2 у пам'яті, демо-користувачі
# http://localhost:8080  ->  user / uSe%r456   або   admin / @Dm1n789
./mvnw verify                # модульні + архітектурні тести, звіт JaCoCo у target/site/jacoco
```

Запуск в Azure (профіль `prod`) — див. [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

Архітектурні рішення (ADR-1…7) і схема модулів — у [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

| № | Перевірка |v 1.0 |v 2.0 |

| T4 | Валюта поза довідником (`BTC`) | - приймається | + відхиляється |

| T7 | 20 паралельних зняттів по 100 з балансу 1000 | - записано 20 операцій (2000), а з балансу списано лише 500 | + рівно 10 операцій, баланс 0 |
| T8 | Клієнт закриває чужий рахунок | - рахунок видалено | + заборонено |
| T9 | Закриття рахунку з коштами | - кошти й історія зникають | + заборонено; історія зберігається |

## Безпека: дія, яку потрібно виконати власнику вихідного репозиторію

У версії 1.0 файл `application-prod.yml` з паролем застосунку Gmail потрапив в історію Git.
Цей пароль потрібно **відкликати** в налаштуваннях облікового запису Google (App passwords).
Видалення файлу в новому коміті не прибирає пароль з історії репозиторію.
