Mini Banking App

Хмарна банківська система на базі Spring Boot та Microsoft Azure

Демо-вхід

Про проєкт

Даний програмний комплекс є результатом дипломного проєктування. Він демонструє реалізацію сучасного банківського API з використанням мікросервісних підходів у монолітній архітектурі, розгорнутій у хмарі.

Технологічний стек (Backend)
  • Java 17 & Spring Boot 3
  • Spring Security (RBAC + BCrypt)
  • Spring Data JPA & Azure SQL

Функціональні модулі

🔐
Безпека

Багаторівнева автентифікація та рольова модель доступу (User/Admin).

💳
Транзакції

Механізм Deposit/Withdraw з підтримкою ACID транзакцій у БД.

☁️
Azure Cloud

Розгортання на Azure Virtual Machine з використанням Manual Deployment.

Інфраструктура Azure

User Client
Nginx (Proxy)
Spring Boot App
Azure SQL DB
